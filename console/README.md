# 自作VMゲーム機：ゲーム選択メニュー

paintbot・宝取り競争・迷路・Dot Chaseを選んで起動できます。以下はmacOS上の手順です。取得した `paintbot-vm/` の直下で実行します。開発者のZero 2 Wでは両ボット対戦ゲームの対戦、迷路とDot Chaseの実画面操作、段階7反映後のOS再起動とメニュー自動表示を確認済みです。公開用のpi設定での実機適用は未実施です。公開版の取得やローカルでのビルドでは、実機の設定は変更しません。

```sh
make setup
console/build/game-console
```

ゲーム選択では、番号とEnterで各ゲームへ進みます。

- `1: Paintbot`：既存の登録ボットから2〜4体を選びます。同じ登録名の重複参加はできません。登録方法は [game/PLAYING.md](../game/PLAYING.md) を参照してください。
- `2: Treasure`：宝取り競争専用の付属ボットから2〜4体を選びます。`1: seeker-h`、`2: seeker-v`、`3: right`、`4: wait`。登録操作は不要で、同じ種類を複数選べます。
- `3: Maze`：迷路をすぐに起動します。W/A/S/Dで移動、Rで最初から、Qでゲーム選択へ戻ります。端末ではEnter不要です。ゴール後はEnterまたはQで戻ります。[迷路の詳細](../maze/README.md)を参照してください。
- `4: Dot Chase`：W/A/S/Dで移動、入力なしで停止、Rで最初から、Qで戻ります。結果画面はEnterでも戻れます。移動キーの入力にEnterは不要です。[遊び方とVM仕様](../dotchase/README.md)を参照してください。

宝取り競争のボット選択では、2体なら `1 2`、4体なら `1 2 1 2` と入力します。参加者の表示を確認し、`y` とEnterで開始します。取消はEnterまたは `n`。ルールと単独起動方法は [treasure/README.md](../treasure/README.md) を参照してください。

paintbotと宝取り競争は試合後にEnterでボット選択へ戻り、そこで `q` とEnterを押すとゲーム選択へ戻ります。ゲーム選択で `q` とEnterを押すとゲーム機プログラムを終了します。OSのシャットダウンは行いません。

起動できない場合や異常終了した場合は、状態を表示して選び直せます。宝取り競争の選択済みボットが見つからない場合は試合を開始せず、ビルドを案内します。試合中のCtrl-Cは試合を中断する操作で、その後Enterを押すとボット選択へ戻れます。

メニューは64桁×24行以上のANSI対応端末を想定します。上記のビルド後、メニューの検証は次のコマンドで実行します。実VMの2試合を観戦するため、約80秒以上かかります。

```sh
make -C console test
```

実機への転送・検証手順は [DEVICE.md](DEVICE.md) を参照してください。転送ツールは自動起動設定を変更しません。開発計画と確認状況は [game-console-roadmap.md](../game-console-roadmap.md) を参照してください。
