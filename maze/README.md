# 迷路ゲーム

段階6の、人がキーで操作するゲームです。C側で入力・描画・ゲーム処理を行い、自作VMは使いません。VMの描画・入力・時間制御の拡張は段階7の計画です。

プロジェクト直下で `make run` を実行し、`3: Maze` を選びます。単独起動は `make -C maze` の後に `maze/build/maze`。

- `W/A/S/D`：上・左・下・右。大文字・小文字の両方に対応し、端末ではEnter不要です。
- `R`：スタート位置に戻り、移動回数をゼロにします。
- `Q`：ゲーム選択へ戻ります。単独起動の場合は終了します。

`@` がプレイヤー、`#` が壁、`S` がスタート、`G` がゴールです。17列×9行の固定迷路で、壁には進めません。移動できた場合だけ移動回数を加算します。ゴールでクリア画面を表示し、EnterまたはQで戻ります。再びゲームを選ぶと最初から始まります。

64桁×24行以上の端末を想定し、ANSI対応端末では画面を書き直します。端末入力はゲーム中だけEnter待ちとエコーを解除し、通常終了・クリア・Ctrl-C・SIGTERM・SIGHUPで元に戻します。強制終了のSIGKILLでは復元処理は実行できません。パイプ入力では1バイトずつ読み取り、改行を読み飛ばします。

```sh
make -C maze test
```

表示した盤面から経路を探索してクリアできること、壁・無効入力・再開・EOF、疑似端末でのEnter不要の操作・端末設定復元・メニュー往復を確認します。MacとZero 2 Wの両方で成功し、実機の稼働先への反映・サービス再起動も成功しました。10インチ実画面での迷路操作もユーザー申告で確認済みです。
